## Contact maps

- Office pin: Google Maps embed on `contact.html` (Department of Geography / Walker Building).
- Global visitors: [MapMyVisitors](https://mapmyvisitors.com/) widget — set `mapMyVisitorsId` in `js/site-config.js` to the `d=` value from your embed code.

Locally:

1. Click **Edit site**
2. Click any text in the page body to change it
3. Click any image to set a new URL or upload a local image
4. Click **Save** (also auto-saves on blur / Ctrl+S)
5. Click **Export page HTML** and replace the file in this repo to publish permanently

To temporarily force the editor on a live URL, set `FORCE_ENABLE_EDITOR = true` in `js/editor.js` (remember to turn it back to `false` before publishing).

## Deploy

Push to `main` on `ruixiang-liu.github.io` and enable GitHub Pages (Settings → Pages → Deploy from `main` / `/`).
